# Campus Customs Desk (frontend)

The React + Vite + TypeScript board for the Campus Customs agent team. It calls the FastAPI backend at
`http://localhost:8000` (set `VITE_API_BASE` to change it).

```bash
npm install
npm run dev      # http://localhost:5173
```

See the main `README.md` for the full start-up order and `../output/design.md` for the design decisions.
